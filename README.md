# Desafio-SQL-Oficina

Sistema de controle e gerenciamento de execução de **Ordens de Serviço (OS)** em uma oficina mecânica.

- Clientes levam veículos para conserto ou revisão periódica
- Uma equipe de mecânicos avalia, preenche a OS e executa os serviços
- A OS reúne os serviços realizados e as peças utilizadas, compondo o valor total
